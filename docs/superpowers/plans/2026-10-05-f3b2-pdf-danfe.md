# F3b2: PDF (DANFE) da NF-e: plano de implementação

> **Para executores:** SUB-SKILL OBRIGATÓRIA: `superpowers:executing-plans` (modo Native). Passos com `- [ ]`.

**Objetivo:** o usuário abre o DANFE em PDF de qualquer NF-e autorizada, em cancelamento ou cancelada, gerado sob demanda a partir do XML.

**Arquitetura:** interface `GeradorDeDanfe` (Domain) com implementação `SpedDaGeradorDeDanfe` (Infrastructure/Pdf) sobre `nfephp-org/sped-da`; Action `GerarDanfe` escolhe o XML pelo status e devolve `ArquivoPdf`; `NotaController::pdf` responde inline; o frontend ganha o link "Abrir DANFE (PDF)".

**Stack:** Laravel 12 / PHP 8.2, `nfephp-org/sped-da ^1.1`, PHPUnit, Next/vitest.

**Spec:** `docs/superpowers/specs/2026-10-02-f3b2-pdf-danfe-design.md`. **Skill fiscal:** `br-fiscal-note-emission` (PDF imprime o que foi autorizado, vem do XML, nunca de colunas paralelas).

## Global Constraints

- `declare(strict_types=1)` em todo PHP; TypeScript strict, sem `any`.
- Nenhuma regra tributária no gerador: ele só desenha o XML recebido.
- PDF **nunca** é armazenado; gera a cada pedido.
- Endpoint do grupo `empresa` (`/api/app`), com o Global Scope do tenant; nota de outro tenant dá 404.
- Erros de negócio no formato `{message, codigo}` via `ErroDeNegocio`.
- Sem push. Commits locais na `master`, um por tarefa.
- Comandos PHP em `backend/`: `php artisan test`, `vendor/bin/pint`, `vendor/bin/phpstan analyse`. Frontend em `frontend/`.

## Review Focus

- XML de `CANCELADA` que não seja o `nfeProc` (fallback cru da F3b1) não pode virar base: usa `xml_autorizado` com `cancelada=true`.
- cStat 136 de cancelamento: a biblioteca não o reconhece sozinha; `setCancelFlag(true)` garante a marca.
- Número nulo no nome do arquivo (nunca para as três situações com PDF, mas o nome não pode quebrar).
- Papel LEITURA abre o PDF; usuário sem sessão recebe 401; outro tenant 404.
- XML corrompido vira 422 com `PDF_INDISPONIVEL`, não 500.

namespace Tests\Fixtures;

/** Descomprime os streams Flate do PDF e junta o texto, para asserções de conteúdo. */
trait TextoDePdf
{
    private function textoDoPdf(string $pdf): string
    {
        $texto = '';
        if (preg_match_all('/stream\r?\n(.*?)\r?\nendstream/s', $pdf, $m)) {
            foreach ($m[1] as $bruto) {
                $dados = @gzuncompress($bruto);
                $texto .= $dados === false ? $bruto : $dados;
            }
        }

        return $texto;
    }
}

declare(strict_types=1);

namespace App\Modules\Fiscal\Infrastructure\Pdf;

use App\Modules\Fiscal\Domain\Contracts\GeradorDeDanfe;
use App\Modules\Fiscal\Domain\Exceptions\PdfIndisponivelException;

}

```php
<?php // Application/Actions/GerarDanfe.php

declare(strict_types=1);

namespace App\Modules\Fiscal\Application\Actions;

use App\Modules\Fiscal\Application\Emissao\ArquivoPdf;
use App\Modules\Fiscal\Domain\Contracts\GeradorDeDanfe;
use App\Modules\Fiscal\Domain\Enums\StatusNota;
use App\Modules\Fiscal\Domain\Exceptions\NotaSemPdfException;
use App\Modules\Fiscal\Domain\Models\Nota;

/** O PDF vem sempre do XML (o que foi autorizado), nunca de colunas paralelas, e nada é gravado. */
final class GerarDanfe
{
    public function __construct(private readonly GeradorDeDanfe $gerador) {}

    public function executar(Nota $nota): ArquivoPdf
    {
        $nota->makeVisible(['xml_autorizado', 'xml_cancelamento']);

        [$xml, $cancelada] = match ($nota->status) {
            StatusNota::Autorizada, StatusNota::Cancelando => [$nota->xml_autorizado, false],
            StatusNota::Cancelada => [$this->xmlDaCancelada($nota), true],
            default => throw new NotaSemPdfException,
        };

        if ($xml === null || $xml === '') {
            throw new NotaSemPdfException('O XML desta nota não está disponível para gerar o DANFE.');
        }

        return new ArquivoPdf('DANFE-'.($nota->numero ?? 'sem-numero').'.pdf', $this->gerador->gerar($xml, $cancelada));
    }

    private function xmlDaCancelada(Nota $nota): ?string
    {
        $cancelamento = $nota->xml_cancelamento;

        return is_string($cancelamento) && str_contains($cancelamento, '<nfeProc') ? $cancelamento : $nota->xml_autorizado;
    }
}
```
