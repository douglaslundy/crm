# F3c3: EPEC da NF-e — Plano de Implementação

> **Para agentes:** SUB-SKILL OBRIGATÓRIA: use `superpowers:subagent-driven-development` (recomendado) ou `superpowers:executing-plans` para executar este plano tarefa a tarefa. Os passos usam caixas `- [ ]`.

**Objetivo:** a NF-e que perde a comunicação com a SEFAZ da UF entra em EPEC (`tpEmis=4`), fica em `CONTINGENCIA` com prazo de 7 dias, é retransmitida e tem DANFE com o registro EPEC.

**Arquitetura:** EPEC é um tipo de contingência da mesma nota (`notas.contingencia_tipo`), sem status novo. O `MontadorDeXml` remonta a NF-e com `tpEmis=4`; o `EmissorDeNfe` ganha `prepararEpec` (sem rede) e `registrarEpec` (evento 110140 no Ambiente Nacional); a Action `EntrarEmEpec` orquestra, e `RetransmitirNota`, o comando horário, o painel e a tela da F3c2 passam a valer para os dois tipos.

**Stack:** Laravel 12 / PHP, `nfephp-org/sped-nfe` 5.2.8, `nfephp-org/sped-da`, PHPUnit, Next.js + React + Vitest.

**Spec:** `docs/superpowers/specs/2026-10-06-f3c3-epec-nfe-design.md`. Referência: `docs/referencia-fiscal/03-nfephp-nfe.md` (seção "Contingência EPEC") e `docs/referencia-fiscal/04-nfephp-nfce.md`.

## Global Constraints

- Nunca chutar valor fiscal: dado ausente no XML bloqueia com mensagem acionável; sem default; zero é valor válido (`=== null`, nunca `empty()` nem `?? 0`).
- Contingência só entra por **falha real de comunicação** (`FalhaDeComunicacaoException`), nunca por rejeição, schema ou configuração.
- Regra tributária fica fora dos providers; o motor só traduz formato.
- `declare(strict_types=1)` em todo PHP. TypeScript strict, sem `any`.
- Mudança de schema só por migration. Nenhum dado real em fixtures.
- Todo Model de tenant já tem Global Scope; **nenhum endpoint novo** nesta fatia (o isolamento de `POST /notas/{nota}/retransmitir` já está coberto pela F3c2).
- Prazo do EPEC: `FISCAL_EPEC_PRAZO_HORAS` padrão **168**; alerta `FISCAL_EPEC_ALERTA_HORAS` padrão **48**.
- Mensagens ao usuário em pt-BR. Commits em pt-BR, terminando com as duas linhas de atribuição abaixo (use `-m` duas vezes, como nos passos).

<?php

declare(strict_types=1);

namespace App\Modules\Fiscal\Infrastructure\NfePhp;

use App\Modules\Fiscal\Domain\Exceptions\EmissaoBloqueadaException;
use DOMDocument;
use DOMElement;

/**
 * Corpo do evento EPEC (110140), lido do XML já montado: UF, IE, destinatário e totais que a NF-e autorizada depois
 * precisa repetir. Reproduz `Tools::sefazEPEC()` (inalcançável na sped-nfe 5.2.8) sem completar nenhum dado ausente.
 */
final class MontadorDoEventoEpec
{
    /** @return array{chave: string, tagAdic: string} */
    public function montar(string $xml, string $cOrgaoAutor, string $verAplic): array
    {
        $dom = new DOMDocument('1.0', 'UTF-8');
        $dom->preserveWhiteSpace = false;
        if (! @$dom->loadXML($xml)) {
            throw $this->ausente('o XML da NF-e em EPEC é ilegível');
        }

        $infNFe = $this->no($dom, 'infNFe');
        $chave = substr($infNFe->getAttribute('Id'), 3, 44);
        if (strlen($chave) !== 44) {
            throw $this->ausente('a chave de acesso da NF-e');
        }
        if (substr($chave, 0, 2) !== $cOrgaoAutor) {
            throw $this->ausente("a UF do emitente ({$cOrgaoAutor}) não é a UF da chave (".substr($chave, 0, 2).')');
        }

        $emit = $this->no($dom, 'emit');
        $dest = $this->no($dom, 'dest');
        $total = $this->no($dom, 'total');

        $ieEmitente = $this->texto($emit, 'IE', 'a inscrição estadual do emitente');
        $dhEmi = $this->texto($dom->documentElement, 'dhEmi', 'a data de emissão');
        $tpNF = $this->texto($dom->documentElement, 'tpNF', 'o tipo da operação');
        $ufDest = $this->texto($dest, 'UF', 'a UF do destinatário');
        $vNF = $this->texto($total, 'vNF', 'o valor total da nota');
        $vICMS = $this->texto($total, 'vICMS', 'o valor do ICMS');
        $vST = $this->texto($total, 'vST', 'o valor do ICMS ST');

        $idDest = match (true) {
            $this->existe($dest, 'CNPJ') => '<CNPJ>'.$this->texto($dest, 'CNPJ', 'o CNPJ do destinatário').'</CNPJ>',
            $this->existe($dest, 'CPF') => '<CPF>'.$this->texto($dest, 'CPF', 'o CPF do destinatário').'</CPF>',
            $this->existe($dest, 'idEstrangeiro') => '<idEstrangeiro>'.$this->texto($dest, 'idEstrangeiro', 'o documento do destinatário').'</idEstrangeiro>',
            default => throw $this->ausente('o documento do destinatário'),
        };
        $ieDest = $this->existe($dest, 'IE') ? '<IE>'.$this->texto($dest, 'IE', 'a IE do destinatário').'</IE>' : '';

        $tagAdic = "<cOrgaoAutor>{$cOrgaoAutor}</cOrgaoAutor><tpAutor>1</tpAutor><verAplic>".htmlspecialchars($verAplic, ENT_XML1).'</verAplic>'
            ."<dhEmi>{$dhEmi}</dhEmi><tpNF>{$tpNF}</tpNF><IE>{$ieEmitente}</IE>"
            ."<dest><UF>{$ufDest}</UF>{$idDest}{$ieDest}<vNF>{$vNF}</vNF><vICMS>{$vICMS}</vICMS><vST>{$vST}</vST></dest>";

        return ['chave' => $chave, 'tagAdic' => $tagAdic];
    }

    private function no(DOMDocument $dom, string $nome): DOMElement
    {
        $no = $dom->getElementsByTagName($nome)->item(0);
        if (! $no instanceof DOMElement) {
            throw $this->ausente("o grupo {$nome} da NF-e");
        }

        return $no;
    }

    private function existe(DOMElement $pai, string $nome): bool
    {
        $no = $pai->getElementsByTagName($nome)->item(0);

        return $no !== null && trim($no->nodeValue ?? '') !== '';
    }

    private function texto(DOMElement $pai, string $nome, string $descricao): string
    {
        $no = $pai->getElementsByTagName($nome)->item(0);
        $valor = $no === null ? null : trim($no->nodeValue ?? '');
        if ($valor === null || $valor === '') {
            throw $this->ausente($descricao);
        }

        return htmlspecialchars($valor, ENT_XML1);
    }

    private function ausente(string $o_que): EmissaoBloqueadaException
    {
        return new EmissaoBloqueadaException('FISCAL_EPEC_DADO_AUSENTE', "Não foi possível registrar o EPEC: falta {$o_que}. Corrija o cadastro e emita de novo.");
    }
}

            return null;
        }

        return in_array($consulta->situacao, [SituacaoNaSefaz::Autorizada, SituacaoNaSefaz::Cancelada], true) ? $consulta : null;
    }

use App\Modules\Fiscal\Domain\Models\NotaEvento;
use App\Modules\Tenancy\Domain\Models\Tenant;
use Carbon\CarbonImmutable;
use Illuminate\Support\Facades\DB;

/**
 * NF-e que perdeu a comunicação com a SEFAZ da UF: remonta com tpEmis 4, registra o EPEC no Ambiente Nacional e guarda
 * o XML assinado para retransmitir em até 7 dias. Só é chamada para falha REAL de comunicação; antes de entrar,
 * consulta a chave original para nunca duplicar a nota.
 */
final class EntrarEmEpec
{
    public const JUSTIFICATIVA = 'Falha de comunicação com a SEFAZ na emissão; emitida em contingência EPEC.';

    public function __construct(
        private readonly EmissorDeNfe $emissor,
        private readonly AplicarResultadoDaEmissao $aplicar,
        private readonly ConsultarChaveOriginal $consultarChaveOriginal,
    ) {}

    public function executar(string $notaId): Nota
    {
        $nota = Nota::query()->findOrFail($notaId);
        if ($nota->status !== StatusNota::Processando || $nota->modelo !== ModeloDocumento::Nfe) {
            return $nota;
        }
        $emitente = Emitente::query()->findOrFail($nota->emitente_id);

        $consulta = $this->consultarChaveOriginal->executar($emitente, $nota);
        if ($consulta !== null) {
            return $this->aplicar->aplicarConsulta($nota->id, $consulta);
        }

        $agora = CarbonImmutable::now();
        $dto = NotaParaEmissao::deNota($nota, $emitente, Tenant::query()->findOrFail($nota->tenant_id));
        $xml = $this->emissor->prepararEpec($emitente, $dto, self::JUSTIFICATIVA, $agora);

        // O envio fica fora da transação: não segura lock de linha durante a rede.
        try {
            $registro = $this->emissor->registrarEpec($emitente, $dto, $xml);
        } catch (FalhaDeComunicacaoException) {
            return $this->aplicar->executar($nota->id, ResultadoDeEmissao::erro('SEFAZ e Ambiente Nacional indisponíveis ao registrar o EPEC. Tente novamente: o número foi preservado.'));
        }
        if (! $registro->registrado) {
            return $this->aplicar->executar($nota->id, ResultadoDeEmissao::erro("EPEC não registrado (cStat {$registro->cstat}): {$registro->motivo}"));
        }

        return DB::transaction(function () use ($notaId, $xml, $registro, $agora): Nota {
            $nota = Nota::query()->whereKey($notaId)->lockForUpdate()->firstOrFail();
            if ($nota->status !== StatusNota::Processando) {
                return $nota;
            }
            $chaveOriginal = $nota->chave;
            $nota->forceFill([
                'status' => StatusNota::Contingencia, 'chave' => $xml->chave, 'xml_enviado' => $xml->xml,
                'cstat' => null, 'motivo' => null, 'mensagem_erro' => null,
                'contingencia_tipo' => TipoDeContingencia::Epec, 'contingencia_desde' => $agora,
                'contingencia_limite_em' => $agora->addHours(TipoDeContingencia::Epec->prazoEmHoras()),
                'contingencia_motivo' => self::JUSTIFICATIVA,
                'epec_protocolo' => $registro->protocolo, 'epec_registrado_em' => $agora, 'xml_epec' => $registro->xmlEvento,
            ])->save();
            NotaEvento::registrar($nota, StatusNota::Processando, StatusNota::Contingencia, 'Entrou em EPEC (protocolo '.$registro->protocolo.')'.($chaveOriginal === null ? '' : " (chave original {$chaveOriginal})"));

            return $nota;
        });
    }
}

    /**
     * Notas emitidas sem a SEFAZ (NFC-e offline e NF-e em EPEC) que ainda esperam transmissão. "Em alerta" = faltam menos
     * horas que o alerta do TIPO da nota para o limite gravado na entrada; "vencida" = limite no passado.
     *
     * @return array{quantidade: int, em_alerta: int, vencidas: int, limite_mais_proximo: ?string}
     */
    private function contingencias(string $ambiente, CarbonImmutable $agora): array
    {
        $notas = Nota::query()->where('ambiente', $ambiente)->where('status', StatusNota::Contingencia)
            ->orderBy('contingencia_limite_em')->get(['id', 'contingencia_limite_em', 'contingencia_tipo']);
        $agoraNoBanco = $agora->setTimezone((string) config('app.timezone'));

        $vencidas = 0;
        $emAlerta = 0;
        foreach ($notas as $nota) {
            $limite = $nota->contingencia_limite_em;
            if ($limite === null) {
                continue;
            }
            // Nota anterior à F3c3 não tem tipo: sempre foi offline.
            $alerta = ($nota->contingencia_tipo ?? TipoDeContingencia::OfflineNfce)->alertaEmHoras();
            if ($limite->lt($agoraNoBanco)) {
                $vencidas++;
            } elseif ($limite->lt($agoraNoBanco->addHours($alerta))) {
                $emAlerta++;
            }
        }

        return [
            'quantidade' => $notas->count(),
            'em_alerta' => $emAlerta,
            'vencidas' => $vencidas,
            'limite_mais_proximo' => $notas->first(fn (Nota $n): bool => $n->contingencia_limite_em !== null)?->contingencia_limite_em?->toIso8601String(),
        ];
    }
